# 🌐 Global AI Index (글로벌 AI 최저가 실시간 가격 비교 & 맞춤 추천)

> 국내(한국 🇰🇷) · 중국(🇨🇳) · 미국(🇺🇸) · 유럽(🇪🇺) 등 글로벌 주요 AI 모델과 57개 공급 사이트의 실시간 API 가격, 할인율, 지연시간을 비교하고, 내 작업에 꼭 맞는 AI 모델을 스마트하게 추천해주는 오픈 웹 플랫폼입니다.

---

## ✨ 핵심 기능

1. **AI 작업 맞춤 추천 (Recommender)**
   - 사용자가 하고자 하는 업무(예: 파이썬 코딩 디버깅, 고난도 심층 추론, 가성비 챗봇, 쇼츠 영상 제작, 이미지 생성 등)를 입력하면 최적의 1위 추천 모델과 대안 모델을 자동 매칭.
   - 단일 최저가 공급처 및 예상 비용 정보를 제공하며, 클릭 한 번으로 메인 가격 비교 테이블로 즉시 연동.
   - API Key는 `.env` 환경 변수 파일에 안전하게 보관하여 외부 노출을 원천 차단.

2. **글로벌 150+개 모델 & 57개 공급 사이트 실시간 가격 비교**
   - **국가별 원클릭 필터링**: 전체, 한국(🇰🇷), 중국(🇨🇳), 미국(🇺🇸), 유럽(🇪🇺), 아시아(🇯🇵/🇸🇬/🇮🇳)
   - **카테고리 & 미디어 지원**: 플래그십, 가성비, 경량/소형(모바일·온디바이스), 추론(Reasoning), 오픈소스, 텍스트(Text), 이미지(Image), 비디오(Video), 음악/오디오(Music/Voice)
   - **가격 정렬**: 기본 / 최저가 순(▲) / 최고가 순(▼) 및 모델별 단일 최저가만 보기 모드
   - **3대 뷰 모드**: 테이블 뷰(기본), 모델별 카드 뷰, 공급 사이트별 뷰

3. **내 예상 토큰 사용량 기준 요금 시뮬레이터**
   - 기본적으로 최소화되어 화면을 가리지 않으며, 클릭 시 입력/출력/캐시 토큰 사용량을 지정하여 사이트별 실제 청구액을 실시간 계산.

4. **전체 공급 사이트 & 모델 목록 팝업 모달**
   - 상단 카드를 클릭하면 57개 LLM 공급 사이트 및 152개 비교 모델을 공식 로고와 함께 한눈에 확인하고 검색 가능.

## 🔒 보안 및 API 키 관리 (.env)

API 키는 절대 코드에 하드코딩하거나 깃 저장소에 커밋하지 않습니다.

1. 프로젝트 루트 디렉터리에 `.env` 파일을 생성합니다:
   ```env
   OPENAI_API_KEY=your_openai_api_key_here
   GEMINI_API_KEY=your_gemini_api_key_here
   ANTHROPIC_API_KEY=your_anthropic_api_key_here
   DEEPSEEK_API_KEY=your_deepseek_api_key_here
   ```
2. `.gitignore`에 `.env` 및 환경 변수 파일이 포함되어 있어 깃허브에 푸시되지 않습니다.

## 🚀 로컬 실행 방법

### 방법 1. 로컬 프록시 서버 실행 (API 추천 백엔드 연동)
```bash
python server.py 8088
```
웹 브라우저에서 `http://localhost:8088` 접속

### 방법 2. 일반 정적 웹 서버 실행 (클라이언트 스마트 엔진 내장)
```bash
python -m http.server 8088
```
별도의 백엔드 없이도 내장된 고도화된 클라이언트 스마트 분석 엔진이 작동하여 언제 어디서나 AI 추천 기능을 100% 정상 이용할 수 있습니다.
